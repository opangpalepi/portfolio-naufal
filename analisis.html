Project 05 / 05

Analisis Data

Tugas singkat dari kuliah Statistika menggunakan bahasa pemrograman Python dan Google Colab, Microsoft Word, serta Microsoft Excel. Mempermudah analisis data secara digital dengan output uji, grafik, dan tabel angka yang sesuai dari responden secara acak, cocok dipakai untuk track record data harian, bulanan, dan tahunan.

KategoriData Analysis
Cocok UntukStatistika / Kuliah
ToolsPython, Google Colab, Excel
Tahap 01

Pengolahan Data di Google Colab

Data responden diolah menggunakan Python di Google Colab, mulai dari persiapan data sampai menghasilkan uji statistik dan grafik.

  1. Mengimpor data responden ke Google Colab.
  2. Membersihkan dan merapikan data.
  3. Menghitung statistik deskriptif.
  4. Menjalankan uji statistik sesuai kebutuhan data.
  5. Membuat grafik dan visualisasi.
Output / Hasil

Hasil uji statistik, grafik, dan tabel angka yang menjadi dasar kesimpulan analisis.

Tahap 02

Rekap Data di Microsoft Excel

Data dan hasil perhitungan dirangkum dalam tabel yang rapi agar mudah dibaca dan dipakai ulang.

  1. Menyusun data mentah responden.
  2. Membuat rekap tabel angka.
  3. Merapikan format tabel agar siap masuk laporan.
Output / Hasil

Tabel rekap yang rapi dan siap dipakai untuk laporan.

Tahap 03

Penyusunan Laporan dengan LaTeX

Seluruh hasil analisis disusun menjadi laporan yang terstruktur dan profesional.

  1. Menyusun struktur dan format laporan.
  2. Memasukkan tabel dan grafik hasil analisis.
  3. Compile menjadi dokumen PDF.
Output / Hasil

Laporan akhir berformat PDF yang rapi dan konsisten.

FITUR UTAMA

Python & Colab

Pengolahan data memakai Python di Google Colab.

Responden Acak

Data diambil dari responden secara acak untuk hasil yang objektif.

Uji Statistik

Output uji statistik yang sesuai dengan data yang dianalisis.

Grafik

Visualisasi data dalam bentuk grafik yang mudah dibaca.

Tabel Angka

Ringkasan angka dalam tabel yang rapi di Excel dan Word.

Track Record

Cocok untuk pencatatan data harian, bulanan, dan tahunan.

TOOLS & TEKNOLOGI
