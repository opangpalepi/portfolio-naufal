# Naufal Portfolio

Static portfolio website built with HTML, CSS, and JavaScript.

## Pages

- `index.html` - homepage
- `cp.html` - Company Profile project
- `erp.html` - ERP project
- `crud.html` - CRUD System project
- `pos.html` - POS / Kasir project
- `analisis.html` - Analisis Data project

The project pages and their assets are kept in the repository root and existing asset folders so their relative links continue to work.

## Deploy to Vercel

Import this repository in Vercel and use the **Other** framework preset. No build or install command is required. Set the output directory to `.` (the project root), then deploy. `vercel.json` enables clean URLs, so project pages are served without the `.html` suffix.
